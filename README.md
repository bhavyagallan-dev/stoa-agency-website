# STOA - Cinematic 3D Agency Experience

An immersive, scroll-driven WebGL experience for STOA, a creative growth agency. A liquid-glass dragon - born from light, transformed through fire, ascending at the close - carries the visitor through six realms of brand storytelling.

## Run it

Open `index.html` in any modern browser. No build step. Internet connection required (Three.js, GSAP, fonts and the dragon model load from CDNs).

## Stack

Three.js r128 - custom GLSL liquid-glass shader (chromatic dispersion, animated iridescent reflections, liquid ripple) - GSAP ScrollTrigger - glTF dragon model with procedural fallback - pure CSS volumetric backgrounds - mobile/touch optimized.
